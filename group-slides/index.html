9 parts

  • OutlineEditorNewPro, locked. The preview is free, the code comes with Pro.The plan of a deck before any slide is built: the AI drafts it, the person edits, reorders and approves it.
  • SlideRailNewPro, locked. The preview is free, the code comes with Pro.The list of slide thumbnails: move around, choose slides, reorder, and see each slide's state in words.
  • SlideStageNewPro, locked. The preview is free, the code comes with Pro.The large view of one slide at its true shape, scaled to fit, with its state and things to check.
  • LayoutAlternativesNewPro, locked. The preview is free, the code comes with Pro.Other layouts for one slide, suggested by the AI and compared with the slide as it is. Preview without changing the deck, then apply one or keep the current.
  • DeckChangeReviewNewPro, locked. The preview is free, the code comes with Pro.Review an AI edit that changed several slides: before and after for each slide, Keep or Undo each one or all at once, then save the kept changes as one version.
  • DeckBuildProgressNewPro, locked. The preview is free, the code comes with Pro.Progress for a deck the AI builds slide by slide: slides ready out of the total, the real step, Stop that keeps what is done, and Retry per failed slide.
  • SpeakerNotesNewPro, locked. The preview is free, the code comes with Pro.Notes for one slide: an AI draft held apart until you keep it, "AI draft" or "Edited by you", and the word count and speaking time worked out in code.
  • ExportSheetNewPro, locked. The preview is free, the code comes with Pro.Export a deck as PDF, PowerPoint, images or a link: what the file holds, what needs fixing first (amber) and what will change, then progress, the file name, or Retry.
  • EditScopeChipNewSays exactly what an AI edit will change, such as Slide 3 or Whole deck, and lets the person change it before sending.
