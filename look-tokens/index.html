Timing and easing

How long things take and how they speed up and slow down.

  • 70ms

    Color changes you should not notice.

  • .15s

    Hover and press.

  • .22s

    Things appearing.

  • .38s

    Panels sliding in.

  • cubic-bezier(.2, 0, 0, 1)

    Things arriving: fast, then settling.

  • cubic-bezier(.4, 0, 1, 1)

    Things leaving: slow, then quick.

  • cubic-bezier(.2, 0, .38, .9)

    Things that move and stay on screen.

  • cubic-bezier(.32, .72, 0, 1)

    A sheet or drawer sliding over the page.

  • cubic-bezier(.16, 1, .3, 1)

    A card or view arriving, with a long soft landing.

When someone turns off motion in their device settings, these all drop to zero.
