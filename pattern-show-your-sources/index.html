Patterns/Show your sources

Show your sources

The assistant states a fact. How does a person know it is true?

Put a small numbered mark next to each claim, and list where it came from.

Try it

Assistant:

You can return the lamp within 30 days.1 Refunds usually arrive in about a week.2

High confidenceHigh confidence, supported by multiple sources.

Sources

  1. 1Return policyshop.example.comItems can be returned within 30 days.
  2. 2Shipping timesshop.example.com

How to design it

  1. 1

    Mark each claim

    Add a small number right after the sentence it supports.

  2. 2

    List the sources below

    Give each one a title and a place it came from, so the number leads somewhere.

  3. 3

    Let people open them

    A tap on the number or the card goes straight to the original.

  4. 4

    Say how sure you are

    Add a short note on how well the sources back up the answer.

Do and avoid

Do

  • Keep marks small so the text still reads well.
  • Use real titles people will recognise.
  • Link each mark to its matching source.
  • Add a confidence note when sources are thin.

Avoid

  • Do not list sources that were not used.
  • Do not put one big list at the end with no marks in the text.
  • Do not make up a source to look sure.
  • Do not hide disagreement: when sources conflict or only partly support a claim, say so (the Trust and safety guide has a table for each case).

Why it works

People check things when a claim matters to them, such as a refund or a flight. If checking is one tap away, most people trust the answer without checking. If it is not possible, they stay unsure about everything.
