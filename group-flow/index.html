Asking and showing work

15 parts in this group. Pick one to open it.

15 parts

  • QuestionSetNewPro, locked. The preview is free, the code comes with Pro.One card that asks every missing fact at once, one question at a time, with a single final button.
  • ActivityTraceNewPro, locked. The preview is free, the code comes with Pro.The agent's work shown step by step, each step tagged with who did it, then folded to one line.
  • ReceiptNewPro, locked. The preview is free, the code comes with Pro.Collapse a card the person already answered into one line. It opens again to show the full card.
  • DraftPreviewNewPro, locked. The preview is free, the code comes with Pro.A drafted message shown like an email, with headers and a body that opens up to the full text.
  • CountdownNewPro, locked. The preview is free, the code comes with Pro.A deadline as a large date, the days left in words, and an optional bar of time used.
  • StatusLineNewOne quiet line of status for the top of a screen, such as Case, Flipkart, an amount and Waiting.
  • MoneyNewAn amount that code worked out, in mono with tabular figures, in rupees by default.
  • GlancePanelNewPro, locked. The preview is free, the code comes with Pro.The case at a glance: the deadline, the facts, the rule and the steps, kept in view beside a chat. GlanceSheet is the phone version.
  • ScrollEdgeNewA scrolling area whose top and bottom edges blur gradually, so content softens near the edge instead of meeting a hard line.
  • StatusTickerNewOne line that shows the real current step of an AI run, such as Reading 3 files, and keeps its width so nothing beside it moves.
  • WorkingEdgeNewA calm moving ring in the AI colour around a surface, shown only while the AI is working on it.
  • LiveLogNewPro, locked. The preview is free, the code comes with Pro.A streaming, monospaced log of what an agent is doing, with pause and follow.
  • JsonViewNewPro, locked. The preview is free, the code comes with Pro.Shows a tool call's input or output as a tree you can open level by level, with a copy button.
  • InlineConfirmNewPro, locked. The preview is free, the code comes with Pro.A button that asks "Delete this?" in its own place, with the safe choice focused, instead of opening a dialog.
  • PromptIndexNewPro, locked. The preview is free, the code comes with Pro.A short list of the person's own messages in a long thread, so they can jump back to one.
