# Sandstone

**The design system for AI products.** Parts and patterns for assistants that answer, act and create, with trust built in: sources, confidence, approvals and undo.

**Website:** https://lkb00.github.io/sandstone/

- 132 parts, 15 patterns, case studies, scenes and guides
- Design tokens for light, dark and high contrast
- Checked against WCAG 2.2 AA
- Files for AI coding tools: [`llms.txt`](https://lkb00.github.io/sandstone/llms.txt), [`components.json`](https://lkb00.github.io/sandstone/components.json) and a Markdown page per part

## Plans

The docs, tokens and core parts are free. **Pro** and **Team** unlock every part, the page templates and the AI-agent kit. See [pricing](https://lkb00.github.io/sandstone/#pricing) and the [licence](LICENSE.md).

## What is in this repository

This repository publishes the website. The `gh-pages` branch holds the built site, and it is updated automatically on every release. The source of the paid parts is kept private and delivered to buyers.
