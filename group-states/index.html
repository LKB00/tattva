8 parts

  • EmptyStatePro, locked. The preview is free, the code comes with Pro.A message for an area with nothing in it: a drawing, a title that says why, one line, and one button.
  • IllustrationA small drawing for empty, error, permission and success screens, in dark lines with one green touch.
  • PictogramA one-color line icon, larger than a button icon, for small areas and lists of features.
  • ErrorStatePro, locked. The preview is free, the code comes with Pro.A red message for a problem that can be fixed, with an optional Try again button.
  • RateLimitNoticePro, locked. The preview is free, the code comes with Pro.An amber message that says when a usage limit resets, with an optional Upgrade button.
  • CalloutA message box inside the page, with a color for its mood, an optional title and an optional button.
  • SkeletonA shimmering gray block that holds the place of content while it loads.
  • SpinnerA small spinning ring that shows something is loading.
