OptionChain

Stable

Calls on the left, puts on the right, strike in the middle, as a real table.

Also known as options chain, options table

Install with npm install @tattva/ui (setup), or copy the code from the kit in Downloads.

Tap a price to choose it.

function Example() {
  const [pick, setPick] = useState<ChainPick | null>(null);
  return (
    <OptionChain ariaLabel="NIFTY option chain" expiryLabel="Expiry 30 Oct" spot={24342} rows={rows}
      selected={pick ? { side: pick.side, strike: pick.strike } : undefined} onPick={setPick} />
  );
}

With onPick the price cells are buttons. The chosen one is marked and written out under the table.

UsageCodeDesignAccessibility

When to use it

Lets a person scan strikes and tap one price to start an order.

Made of: Expiry and spot line · Calls and Puts group headers · Column headers · Strike column · Value cells · Price buttons

Use it for

  • Choosing a strike and a side for an order.
  • Comparing open interest and implied volatility across strikes.
  • A small chain in a narrow phone screen.

Not for

  • A general table of records: use DataTable.
  • A single price with a change: use Money.

Do and avoid

Do

  • Keep Price in the columns when you pass onPick.
  • Show the expiry and the spot price.
  • Use a maxHeight for long chains.
  • Pass null for a missing value and let the dash show.

Avoid

  • Do not use gain and loss colours to mark in the money.
  • Do not hide the scroll region on a phone. It is the way to reach the far columns.
  • Do not place an order from onPick. Open an order ticket instead.
  • Do not pass more columns than the width can hold without scrolling in mind.

On a phone

  • The chain scrolls both ways inside its own box, because the table is as wide as its columns. The strike column stays pinned and the header rows stay at the top.
  • Price buttons grow to 44px by 44px on touch screens, so rows get taller there.
  • Show few columns on a phone, since each extra column adds to the sideways scroll.

Works with

  • DataTable
  • NumberField
  • Money

States

States this part has beyond its default look. Build each one your screen can reach. States set by a property are in the Code tab.

at the money
The row with the strike nearest spot gets a strong border, the mark ATM, and the words At the money for screen readers.
in the money
Calls below spot and puts above spot get a grey tint and a small diamond, with the words In the money for screen readers.
selected
The price cell matching selected is filled with the accent and set aria-pressed.
empty value
A null or missing value shows a dash. A null price is plain text, not a button.
scrolling
The region scrolls both ways. The header rows stay at the top and the strike column stays at the edge.
hover
A price button shades when the pointer is over it.
focus
The scroll region and each price button show the focus ring. Up and Down arrows move between rows in the same column.

Built in

  • It is a real table with a caption, two header rows and a row header for each strike.
  • The scroll region has a name and can be reached by keyboard, so the sideways scroll works without a mouse.
  • The nearest strike carries the visible mark ATM and the words At the money for screen readers.
  • In the money cells say so in words for screen readers beside the tint and the diamond.
  • Price buttons have names such as Call 24,350, price 142.50. Up and Down arrows move between rows in the same column. The chosen one is aria-pressed.
  • Values are right aligned with tabular figures. A missing value is a dash.

What you need to do

  1. 1Give it an ariaLabel that names the chain, such as NIFTY option chain.
  2. 2When a price is picked, say what was picked in text. Do not rely on the highlight.
  3. 3Show the expiry in expiryLabel so the table is not read out without it.

Built toward WCAG 2.2 AA and checked automatically; no independent audit yet. Read the accessibility guide
