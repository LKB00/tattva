Foundations/Type guide

Typography

Fonts, sizes and spacing for readable text.

One clean sans for the whole interface, a matching mono for the technical parts. AI products read as precise and calm when the type is quiet, so Tattva keeps it to two families.

Code and step names

One size scale

Every size in Tattva comes from one list. A size sets only the size; set the line height next to it with leading-*, so one choice never hides another. A check stops Tailwind's own sizes, like text-sm, from coming back.

text-nano10Tiny capital labels (12 on touch screens)
text-micro11Badges and counts (12 on touch screens)
text-small12Captions, helper text, timestamps
text-compact13Buttons, list rows, chips
text-body14Interface text and fields
text-body-lg15Chat answers and long reading
text-lead16Card titles, intro lines
text-lead-lg17Large intro lines
text-subhead18Panel and dialog titles
text-title-xs20Small page sections
text-title-sm22Section headings
text-title-md26Page headings on phones
text-title-lg30Page headings
text-head-sm32Big headings
text-head-md40Hero headings
text-display-sm48Display titles

Sizes are in rem, so they grow with the reader's text size setting. The numbers are pixels at the default setting. Larger steps (banner, display-md and up) are for the website and marketing pages.

Why these fonts

  • Geist for the interface and the headings. The main AI assistants use a clean neo-grotesque sans for the whole interface. It reads as modern and neutral, and it lets the answers be the loudest thing on the screen. Geist ships as one variable file, so every weight from 400 to 700 is real. Its digits line up in columns, and it stays clear at 12px.
  • Geist Mono for the technical parts. Use it for code, model names, tool names, token counts and ids. A mono label tells the reader "this is a machine value" without needing a colour.
  • No serif by default. A book serif makes a product feel literary, and a cream page with an italic serif is now so common it no longer sets a product apart. If you want a warmer voice, set data-voice="serif" on the root element and load a serif such as Newsreader: headings and the assistant's greetings switch, and nothing else changes.
  • Both fonts are free and open source (SIL Open Font License), so they are safe to use in any product.

Rules

  • Headings (h1 to h3) use the display style: Geist at semibold with slightly tight letter spacing. Do not go heavier than semibold.
  • Set technical values in Geist Mono: model names, tool names, counts and ids.
  • Keep lines of text near 65 characters. Chats are at most 768px wide.
  • Use evenly spaced digits wherever numbers line up, like times and counts.
  • Use capital letters only for the 10px label style, with extra letter spacing.
  • Pick sizes from the scale above and always pair them with a line height. Never use text-xs, text-sm or other Tailwind sizes.
