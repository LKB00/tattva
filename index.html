What's new

50 releases so far.

All releases
  • 0.29.1Questions the way agents ask themQuestionSet asks an agent's clarifying questions the way agent tools do: a visible Question 2 of 3, a suggested option marked Recommended and listed first, questions that take several answers, You decide and Skip, Use the defaults to end the questions, Back, number keys to pick an option, and a last look at every answer with a Change link before the final button. Every addition is optional, so existing code is unchanged.
  • 0.29.0The names other design systems useEvery part lists what other design systems call it, such as accordion for Sections, description list for FactList and KPI for StatTile. Search on the site, the MCP server and the Figma plugin find a part by any of these names, and each part's page shows them.
  • 0.28.0Results, facts and sections for answersResultCard shows one thing an answer recommends, such as a hotel, a product or a plan: a picture, the name, two to four facts, a price, a tag and one action. While the answer is still streaming the card shows, but its action waits until the answer is complete.
