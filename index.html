Questions

Short answers before you start.

Is it free?+

The previews and guidance are free for all 211 parts. The code for 63 of them is free too, in the free kit. Pro adds the code for the rest, for one payment of $149.

Do I need to be a developer?+

No. Start here asks what you are making and gives you one prompt to paste into Claude, ChatGPT, Cursor, Lovable or v0.

Will my AI coding tool understand it?+

Yes. The MCP server lets Claude Code, Cursor and others look up every part, plan a build and check the code. There is also llms.txt and llms-full.txt.

What does it need?+

React 19, TypeScript and Tailwind CSS v4. Copy the tattva folder and the tokens file into your project.

Is it accessible?+

Every part is built toward WCAG 2.2 AA. Each release is checked automatically: axe in light and dark, a keyboard walk, phone widths and real interactions. There has been no independent audit yet, and the accessibility guide lists what is and is not tested.

Can it look like my product?+

Yes. There are 7 colour themes, three corner styles, and light and dark. Every size, colour and timing is a token you can change in one place.
