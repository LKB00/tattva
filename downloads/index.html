For designers

Colours, sizes and icons to use in your own design tools.

  • Colours and sizes

    tokens.json

    Use it when your design tool can import tokens. Every colour, size and timing, for light and dark.

    Download

  • Figma plugin

    tattva-figma-plugin.zip

    Adds Tattva's parts to a Figma file as components, with colours (light and dark), corners, sizes and text styles, and checks a design for contrast, text size and tap size. Easiest from Figma Community (Get started, Plugins); this file is for working offline: unzip, then in Figma choose Plugins, Development, Import plugin from manifest.

    Download

    icons.zip

    Use it when you need the icons as picture files. They take their colour from the text around them.

Using the tokens

Colors and sizes are named for what they do, such as “surface” or “text muted”, not for how they look. Change the value in one place and every part follows.

var(--surface) · var(--fg) · var(--accent)
