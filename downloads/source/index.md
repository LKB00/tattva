# Tattva free source, in small pieces

Use this when your tool cannot install packages or unzip files, and it shortens long pages. Every file below is small and returned as it is, with nothing left out. Read them in order.

## 1. The parts

Each piece holds several files. A heading like `## tattva/atoms/Button.tsx` is the path: save the code under it as `src/tattva/atoms/Button.tsx`. Import every part from `./tattva` (the `index.ts` in the first piece lists what is exported).

## 2. The colours

Join these 3 files, in order, into one file called `src/tokens/tokens.css` and import it once at the start of the app (`import "./tokens/tokens.css";`). Do not change anything in them. Set `data-palette` on the html element for a colour theme.
