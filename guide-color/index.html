Color

Which colors to use, and when.

Warm paper, charcoal ink, one lime and one amber. Colors come in three layers: a base palette, named roles that components use, and Tailwind classes made from those roles.

Usage rules

  • Main buttons are charcoal. In dark mode they turn lime.
  • Never put lime text on paper. Lime is a fill with charcoal text on top.
  • Amber shows only when a person has to act, and always next to words that say why.
  • Never use color alone. Add an icon, a shape or a label.
  • Body text has a 4.5:1 contrast ratio against its background in both themes. The lightest text color is tuned to pass.
