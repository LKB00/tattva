Tools/Set up/Connect an AI tool

Connect an AI tool

This is optional. It lets your AI tool look things up in Tattva itself, plan the build and check its own code.

Just want to paste a prompt?

No install and it works in any AI tool. Start with the Build brief.

Make my prompt

What you need to connect

  • Node.js 18 or newer (check with node --version; get it at nodejs.org)
  • An AI tool that supports MCP: Claude Code, Cursor or Claude Desktop
  • An internet connection when it starts
  1. 1

    Add the Tattva plugin

    Inside Claude Code, type these two lines, one at a time:

    Claude Code plugin commands
    /plugin marketplace add LKB00/tattva
/plugin install tattva@tattva

    The plugin connects the Tattva server and teaches Claude how to build with Tattva. Rather add only the server? Run claude mcp add tattva -- npx -y @tattva/mcp in a terminal instead. More on the Plugins page.

  2. 2

    Restart Claude Code and try it

    Type /tattva:build and say what you want, for example "a chat assistant for my bank." It asks a few quick questions, one at a time; say "defaults" to skip them. Also there: /tattva:find to find a part, /tattva:review to check your code and /tattva:theme to pick colours.

If something goes wrong

"node: command not found"
Node.js is missing. Install it from nodejs.org, then open a new terminal.
The tool does not list Tattva
Check that npx -y @tattva/mcp in a terminal says "Tattva MCP server is working" (stop it with Ctrl+C), then restart the tool.
"could not read … from the live site"
The helper needs the internet when it starts. Check your connection and restart the tool.
