7 improved parts · 3 changes

Improved parts

Each page's footer says what changed.

  • QuestionSetOne card that asks every missing fact at once, one question at a time, with a single final button.
  • AutonomyLevelSwitch between a short summary, each step, or every detail of what an assistant did.
  • ContextChipA small tag near the message box that shows what the chat is about.
  • MeterA thin bar that shows how much of something is used, and turns amber past a set point.
  • KbdA small key label, such as Tab or Esc, that shows which key to press.
  • CatchUpSummaryA "While you were away" summary shown when you come back to a run.
  • ApprovalInboxOne list of everything across your runs that is waiting for you.

Everything in this release

  • QuestionSet asks an agent's clarifying questions the way agent tools do: a visible Question 2 of 3, a suggested option marked Recommended and listed first, questions that take several answers, You decide and Skip, Use the defaults to end the questions, Back, number keys to pick an option, and a last look at every answer with a Change link before the final button. Every addition is optional, so existing code is unchanged.Updated
  • Every part lists what other design systems call it, such as accordion for Sections, description list for FactList and KPI for StatTile. Search on the site, the MCP server and the Figma plugin find a part by any of these names, and each part's page shows them.New
  • Six parts take the industry name: AltitudeToggle is now AutonomyLevel, ContextPill is ContextChip, MeterBar is Meter, KeyHint is Kbd, ReEntryRecap is CatchUpSummary and NeedsYouInbox is ApprovalInbox. The old names still work until 0.31.0, old page addresses open the new page, and review_code says what to change.Updated
