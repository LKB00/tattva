Everything in this release

  • All 223 components are free, with their full code. There is no Pro, no licence key and no paid plan.New
  • The npm package, the download, the AI-tools kit and the Figma plugin now hold every component. The Claude Code plugin and MCP server give the full code of every part.Updated
  • The Pricing page, the Pro tags and locks, and the Redeem page are gone. Old links to them open Downloads.Updated
  • The licence now says plainly that you may use Tattva in any project, personal or commercial, and change it as you like.Updated
