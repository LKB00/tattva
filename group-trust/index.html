  • AILabelPro, locked. The preview is free, the code comes with Pro.A small lime tag that says content was made by AI and explains how. Once a person edits the content, it becomes an undo button.
  • AIMarkA small four-point shape that tells people something was made by AI.
  • AIBadgeA lime-tinted badge with a sparkle that marks content made by AI.
  • AIDisclosureA small centered note reminding people to check the assistant's answers.
  • ProvenancePopoverPro, locked. The preview is free, the code comes with Pro.A label that says content was made with AI, and opens a short note on how.
  • CitationMarkerA small numbered link that points to a source, placed after a claim in a reply.
  • CitationHoverCardPro, locked. The preview is free, the code comes with Pro.A small number in a sentence that shows where a fact came from.
  • SourceCardPro, locked. The preview is free, the code comes with Pro.A numbered link card for one source.
  • SourceListPro, locked. The preview is free, the code comes with Pro.The numbered sources behind an answer, shown in two columns.
  • ConfidenceIndicatorPro, locked. The preview is free, the code comes with Pro.Three bars and a label that show how sure the assistant is about an answer.
  • FeedbackBarPro, locked. The preview is free, the code comes with Pro.Thumbs up and down buttons, with a short list of reasons after a thumbs down.
  • RefusalNoticePro, locked. The preview is free, the code comes with Pro.A calm notice for a request the assistant will not do, with an optional alternative.
  • SummaryCardPro, locked. The preview is free, the code comes with Pro.An AI-written overview with its sources, a warning to double-check, and a way to give feedback.
  • RevertTogglePro, locked. The preview is free, the code comes with Pro.Lets people flip between the AI's suggestion and their own edit, with a way back to the original.
