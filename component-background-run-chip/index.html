BackgroundRunChip

Stable

A small chip for a run in the background that opens its details.

Install with npm install @tattva/ui (setup), or copy the code from the kit in Downloads.

Four runs in a row

Choose a run to see its details.

<BackgroundRunChip name="Invoices" status="needs-input" statusText="Needs you" elapsed="12 min" onClick={() => openDetails("invoices")} />

Press a chip to open its details. The run that needs you is amber.

UsageCodeDesignAccessibility

When to use it

A small pill for a run that keeps going while the person does other things. It stays calm while the run works and turns amber only when the run needs the person.

Made of: State icon · Run name · Short status · Time elapsed

Use it for

  • A row of background runs in a header or footer.
  • Opening a run's details or a quick peek.
  • Drawing attention to a background run that is waiting on the person.

Not for

  • A full list of runs with summaries and replies: use AgentSessionList.
  • Saying who is in control of the screen: use TakeoverBar.
  • A status that nobody needs to press: use AgentStatusIcon.

Do and avoid

Do

  • Use it where space is tight, such as a header or a side rail.
  • Keep the status to two or three words.
  • Open a peek or panel with the full story on press.
  • Group chips that need you first.

Avoid

  • Do not use amber for working, done or failed runs.
  • Do not put more than a name and a short status in the chip.
  • Do not use a chip for an action. It only opens details.
  • Do not let the elapsed time tick every second for screen readers.

On a phone

  • The chip never grows wider than its container, and the name and status text are cut with an ellipsis when they do not fit.
  • Nothing shows the full text of a cut name on a phone, so keep names and status words short.
  • On a touch screen the chip keeps its size and has a 44px tap area.

Seen in products

  • Claude Code agent view: each session has a state icon, and Space opens a peek panel with the question and a reply box.
  • Claude Code lets a command run in the background and keeps it visible.
  • Microsoft: background work stays easy to reach and mostly out of the way.
  • Claude Code docs, agent view (opens in a new tab)
  • Microsoft Design, UX design for agents (opens in a new tab)

Works with

  • AgentStatusIcon
  • NeedsYouInbox
  • AgentSessionList

Used in Come back after time away.

Properties

elapsedstringnoneTime the run has been going, such as 4 min.

Tokens

Change one of these and every part that uses it follows.

  • --attention-soft
  • --attention-fg
  • --surface
  • --line
  • --radius-control

Built in

  • It is one real button, and its name reads the state, the run name, the status and the time together.
  • Amber comes with the words Needs you and a question-mark icon, so it does not rely on color.
  • It tells screen readers whether its panel is open when you pass expanded.
  • The spinning icon stops when people turn off motion in their system settings.

What you need to do

  1. 1Pass expanded while the panel it opens is showing. Leave it out if the chip goes to another page.
  2. 2Keep statusText short, because it is read in the button name with the run name and time.
